**Zenix Service Suite v1.15.5** is a lightweight, ultra-fast, and completely open-source PC tweaker written entirely in classic **Windows Batch scripting (.bat)**. 

This stable milestone fixes legacy menu loops, completely wipes hidden OS junk, flushes Discord media trash, and helps gamers maximize their system performance and eliminate micro-stutters!

---

## ⚡ Main Technical Features:
* 🛠️ **MODULE_CLEAN** — Force closes heavy background tasks and performs a deep purge of system `Temp` folders and Microsoft telemetry logs.
* 🏎️ **MODULE_STEALTH** — Unloads heavy launchers from RAM and wipes the NVIDIA Shader Cache (`DXCache`) to stabilize 1% Low FPS.
* 🌐 **MODULE_NET** — Resets the network stack (`winsock`, `int ip`) and instantly reclaims your network link via an active DHCP refresh without forcing a system reboot.
* ⚙️ **MODULE_TWEEKS** — Hard-cleans hidden Discord asset cache directories to free up local storage space.
* 📊 **Hardware Passport** — Native hardware specification logging with precise mathematical rounding for accurate 32GB RAM detection.

## ⚡ Главные фишки сборки v1.15.5 STABLE:
* 🛠️ **БЫСТРАЯ ОЧИСТКА** — Безопасное удаление логов телеметрии Windows, очистка системных папок и временных файлов `Temp`.
* 🏎️ **ИГРОВОЙ СТЕЛС-РЕЖИМ** — Выгрузка тяжелых фоновых процессов лаунчеров и тотальный снос кэша шейдеров NVIDIA (`DXCache`) для стабилизации микрофризов.
* 🌐 **СЕТЕВОЙ РЕАНИМАТОР** — Полный сброс сетевого стека с мгновенным автоматическим обновлением IP по DHCP (интернет не пропадает и перезагрузка не нужна!).
* ⚙️ **ТВИКИ ОТ ZENIX** — Глубокое удаление скрытого мусора, картинок и гифок кэша из мессенджера Discord.
* 📊 **МОНИТОРИНГ ЖЕЛЕЗА** — Быстрый и честный опрос характеристик ПК (процессор, видеокарта, плата и правильный вывод 32 ГБ ОЗУ через PowerShell).
